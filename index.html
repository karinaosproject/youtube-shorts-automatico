🎬 Karina OS

Criador automático de conteúdo
💡 As referências funcionam como orientação editorial. O sistema pode usar características gerais de estrutura, ritmo, abordagem, linguagem e narrativa associadas às referências selecionadas.
🛡️ Conteúdo original: as referências NÃO devem ser usadas para copiar frases, roteiros, títulos, textos, exemplos específicos ou sequências identificáveis. O conteúdo final deve ser novo e original, apenas inspirado em características editoriais gerais.
Como funciona:

Você escolhe o tema e as características do vídeo. O pedido será enviado automaticamente para o sistema de produção através de uma Issue do GitHub.

O sistema utiliza essas informações para criar o roteiro, selecionar os visuais, gerar a narração e montar o vídeo automaticamente.
